  • No ads

  • Private by construction

    Everything is encrypted on your phone. The server holds data it has no way to read.

How it works

  1. A group is a link

    Create a group and send its link to your friends. The link carries the group’s key, so anyone who has it can see and edit the group. Share it where you would share the group chat.

  2. Everything is encrypted on your phone

    Amounts, titles, notes, names and the group’s name are locked on your phone before anything is sent, with a key that exists only in the link and on the phones of the people in the group.

  3. The server can’t read it

    The sync server passes locked entries between phones. It can tell when a group is busy, never what is in it. Every phone keeps the whole history, so Even works offline and survives the server losing its copy.

  4. You can run your own

    The protocol is public and the server is small. Point a group at a server you run, and nothing about it goes through ours.
